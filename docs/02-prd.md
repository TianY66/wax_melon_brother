# 冬瓜兄弟：产品需求文档

## 1. 文档目的
本文档用于明确《冬瓜兄弟》MVP 版本的产品范围、核心体验、功能需求、非功能需求与验收标准，为研发、策划、测试提供统一基线。

## 2. 产品概述

### 2.1 产品名称
《冬瓜兄弟》

### 2.2 产品类型
单人俯视角肉鸽生存类游戏

### 2.3 产品目标
- 在 2 周内完成可演示的 MVP
- 形成一局 10 分钟左右的完整游玩体验
- 通过武器、升级、敌人、波次、Boss 体现系统工作量

### 2.4 核心体验关键词
- 上手快
- 爽感强
- 构筑清晰
- 节奏递进
- 完成度高

## 3. 用户画像

### 3.1 核心玩家
- 年龄：16~35 岁
- 偏好：轻量动作游戏、Roguelite、生存割草
- 诉求：快速进入游戏、每局有成长、失败后愿意再来一局

### 3.2 次级用户
- 希望参考完整独立游戏项目结构的开发者
- 希望用完整作品展示能力的求职者或学生团队

## 4. 产品目标与非目标

### 4.1 产品目标
1. 玩家 30 秒内理解玩法。
2. 玩家 20~40 秒内完成首次升级。
3. 玩家 2~3 分钟内感知到武器与被动构筑方向。
4. 玩家在 8~10 分钟时进入明显终局压力。
5. 项目具备主菜单、局内 UI、暂停、结算、重开闭环。

### 4.2 非目标
- 不追求复杂叙事
- 不追求高强度操作难度
- 不追求大量可玩角色
- 不追求大地图探索
- 不追求重度局外养成

## 5. 核心玩法

### 5.1 一句话玩法
玩家通过 `WASD` 控制角色移动与走位，角色自动攻击；击败敌人后收集鲜度能量升级，从三选一中构建武器和强化组合，在 10 分钟怪潮中存活并完成终局挑战。

### 5.2 核心循环
移动走位 -> 自动攻击 -> 击杀敌人 -> 掉落鲜度能量 -> 升级三选一 -> 构筑变强 -> 对抗更强敌人 -> 胜利/失败结算

### 5.3 单局规则
- 单局目标时长：10 分钟
- 失败条件：生命值归零
- 胜利条件：击败最终 Boss，或在 Boss 登场后坚持到倒计时结束

## 6. 功能需求

### 6.1 功能范围总表
| 编号 | 功能 | 描述 | 优先级 |
|---|---|---|---|
| FR-01 | 主菜单 | 开始游戏、设置、退出 | P0 |
| FR-02 | 玩家控制 | WASD 移动、受伤、死亡 | P0 |
| FR-03 | 自动攻击 | 根据武器配置自动释放攻击 | P0 |
| FR-04 | 敌人与伤害 | 敌人追击、接触或技能造成伤害 | P0 |
| FR-05 | 经验与升级 | 掉落鲜度能量、升级三选一 | P0 |
| FR-06 | 波次系统 | 按时间切换敌人池和刷新频率 | P0 |
| FR-07 | HUD | 血条、经验条、等级、时间 | P0 |
| FR-08 | 暂停与结算 | 暂停菜单、胜负结算、重开 | P0 |
| FR-09 | 武器与被动内容 | 4~6 武器、6~10 被动 | P1 |
| FR-10 | 精英与 Boss | 精英怪、Boss、预警机制 | P1 |
| FR-11 | 掉落扩展 | 治疗包、磁吸核心 | P1 |
| FR-12 | 设置与存档 | 音量、窗口模式、基础持久化 | P2 |

### 6.2 详细功能需求

#### FR-01 主菜单
需求说明：
- 显示游戏标题、背景图、开始游戏、设置、退出按钮
- 设置界面至少支持主音量调整与返回

验收标准：
- 玩家可以从主菜单进入战斗
- 玩家可以返回菜单或退出程序

#### FR-02 玩家控制
需求说明：
- 玩家使用 `WASD` 进行 8 方向移动
- 角色具有生命值、移动速度、受伤冷却时间
- 生命归零后进入失败结算

验收标准：
- 玩家移动响应平滑
- 与敌人接触时掉血
- 角色死亡后无法继续操作

#### FR-03 自动攻击
需求说明：
- 玩家无需主动按攻击键
- 武器按冷却时间自动释放
- 支持定向、跟随、范围、落点等不同攻击模式

验收标准：
- 默认武器可稳定自动索敌
- 多武器同时存在时不会互相阻塞

#### FR-04 敌人与伤害
需求说明：
- 敌人具备追击、远程、爆炸、冲锋等基础行为
- 支持生命、速度、伤害、是否精英等差异化属性

验收标准：
- 不同敌人对玩家产生不同压力
- 敌人被击杀后能触发死亡反馈和掉落

#### FR-05 经验与升级
需求说明：
- 敌人死亡掉落鲜度能量
- 玩家拾取后累计经验并升级
- 升级时弹出 3 个选项供玩家选择

验收标准：
- 前 40 秒内应大概率出现第一次升级
- 升级时战斗暂停
- 无效选项不会进入候选池

#### FR-06 波次系统
需求说明：
- 按时间阶段切换刷怪池、最大敌人数和刷新频率
- 后期引入精英与 Boss

验收标准：
- 前中后期敌人组合明显变化
- 波次切换时玩家可感知到压力提升

#### FR-07 HUD
需求说明：
- 显示血条、经验条、当前等级、剩余时间
- 升级选择框和 Boss 预警需清晰可读

验收标准：
- 玩家无需教学即可看懂自身状态
- HUD 不遮挡核心战斗区域

#### FR-08 暂停与结算
需求说明：
- `Esc` 可暂停和恢复
- 失败后显示生存时间、等级、击杀数、主要武器
- 提供“再来一局”和“返回菜单”

验收标准：
- 任意时刻可以暂停
- 结算页面能正确显示关键统计

#### FR-09 武器与被动内容
需求说明：
- MVP 至少提供 4 种武器、6 个被动
- 完整版设计目标为 6 种武器、10 个被动

验收标准：
- 至少形成 2 套不同的可行构筑
- 被动对多个武器可见生效

#### FR-10 精英与 Boss
需求说明：
- 中局开始刷新精英怪
- 终局出现 Boss，并伴随预警表现

验收标准：
- 精英怪有更高血量或额外行为
- Boss 明显区别于普通敌人

#### FR-11 掉落扩展
需求说明：
- 支持治疗包和磁吸核心
- 掉落权重可配置

验收标准：
- 治疗包与磁吸核心能改变玩家当前决策

#### FR-12 设置与存档
需求说明：
- 设置项至少包含音量和显示模式
- 保存最近设置

验收标准：
- 重启游戏后设置仍然生效

## 7. 内容需求

### 7.1 角色
- 可玩角色数量：1
- 当前角色：冬瓜大哥

### 7.2 地图
- 地图数量：1
- 地图名称：夜市后厨
- 结构：中心开阔，边缘有障碍，适合绕圈走位

### 7.3 武器
计划武器：
- 冬瓜籽连发
- 菜刀回旋盘
- 热汤喷壶
- 电磁蒸笼
- 保鲜膜激光
- 小瓜无人机

### 7.4 被动
计划被动：
- 刀工提升
- 火候提升
- 冷却缩减
- 走位加速
- 拾取半径扩大
- 最大生命提升
- 恢复效率提升
- 暴击率提升
- 投射物数量 +1
- 范围伤害提升

### 7.5 敌人
计划敌人：
- 菜刀螨
- 叉勺猎犬
- 压力锅重装体
- 油烟炮台球
- 自爆清洁球
- 冷柜重装箱（精英）
- 搅拌无人机队长（精英）
- 后厨总控机（Boss）

## 8. 非功能需求

### 8.1 性能
- 目标帧率：1080p 下稳定 60 FPS
- 中后期同时存在 120~150 个敌人时不明显卡顿
- 武器、掉落和特效不出现明显内存泄漏

### 8.2 可用性
- 首次游玩无教程也能理解基本操作
- 字体清晰，按钮易点，信息层级明确
- 支持重复开局和快速复盘

### 8.3 稳定性
- 不允许出现阻断流程的死锁、黑屏、无法结算
- 主要功能在连续 3 局测试中可稳定运行

### 8.4 可维护性
- 武器、敌人、波次、升级项必须配置化
- 核心系统需模块分离，避免“巨型脚本”

## 9. 版本范围

### 9.1 MVP 版本
- 1 张地图
- 1 个角色
- 4 种武器
- 6 个被动
- 4 种普通敌人
- 1 个精英
- 1 个 Boss
- 主菜单、局内 HUD、暂停、结算

### 9.2 扩展版本
- 第 5 种、第 6 种武器
- 第 2 个精英
- 更多掉落物
- 简单局外成长

## 10. 发布验收标准

满足以下条件可视为 MVP 可交付：

1. 可以从主菜单进入战斗并完整结束一局。
2. 玩家可移动、自动攻击、拾取经验、升级、死亡结算。
3. 至少存在明显的前中后期节奏变化。
4. 存在 Boss 或明确终局挑战。
5. 无阻断性 Bug，且有基础声音/视觉反馈。
