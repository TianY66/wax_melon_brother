# 冬瓜兄弟：故事列表

## 1. 说明
以下故事列表按照 Epic 分组，覆盖《冬瓜兄弟》MVP 到第一版完整 Demo 的主要开发内容。优先级采用 `P0 / P1 / P2`。

## 2. Epic 列表

- E1：基础进入与主循环
- E2：战斗与成长
- E3：内容扩展
- E4：完成度与反馈
- E5：配置化与可维护性
