# 冬瓜兄弟：第二次迭代说明

## 1. 迭代名称

第二次迭代：双角色 + 波间商店

## 2. 迭代目标

- 引入 2 个可选角色并建立开局差异
- 将连续战斗拆成 6 段波次
- 在前 5 段波次间插入商店
- 引入材料经济，形成“经验升级 / 材料消费”双循环

## 3. 迭代范围

### 3.1 纳入内容

- `data/characters.json`
- 主菜单角色选择
- 冬瓜二哥贴图接入
- `GameState.SHOP`
- 6 段波次配置
- 敌人材料掉落
- 商店面板、购买、刷新、继续战斗
- HUD 材料与波次显示
- 文档同步

### 3.2 不纳入内容

- 第 3 个角色
- 局外材料与持久化经济
- 武器槽上限系统
- 商店锁卡、冻结、退款、合成

## 4. 交付物

- 双角色可玩战斗版本
- 波间商店版本
- 同步更新的产品、设计、测试和汇总文档

## 5. 验收标准

1. 主菜单可切换角色并正确开局。
2. 冬瓜二哥贴图、缩放、偏移显示正常。
3. `90/180/270/360/450s` 正常进入商店。
4. 商店中可购买多个商品，且每店仅 1 次刷新。
5. 升级与商店同帧时先升级后商店。
6. 重开、返回菜单、Boss 节奏不回归坏。
