# 冬瓜兄弟：测试计划

## 1. 测试目标

验证当前版本在双角色、6 段波次、材料经济、波间商店和 Boss 节奏上的正确性、稳定性与可玩性。

## 2. 测试范围

- 主菜单与角色选择
- 玩家移动、受伤、死亡
- 自动攻击与升级三选一
- 敌人行为、材料掉落与波次推进
- 波间商店、刷新与继续战斗
- Boss 预警、Boss 登场、胜负结算
- 暂停、重开、返回菜单

## 3. 关键测试点

### 3.1 角色

- 主菜单可切换大哥/二哥
- 开始后角色贴图、数值、初始武器正确
- 冬瓜二哥体型与大哥接近，不出现过大、漂浮、翻转异常

### 3.2 战斗与商店

- `90/180/270/360/450s` 准时进入商店
- 商店中时间停止，退出后恢复
- 升级与商店同帧触发时，先升级后商店
- 连续升级时面板按次数连续弹出

### 3.3 经济

- 材料按敌人类型正确入账
- 商品扣费正确，买不起时禁用，前中期通常只能购买少量商品
- 已购商品显示“已售出”
- 刷新每店只能 1 次，价格固定 `20`

### 3.4 回归

- 暂停、Boss、结算、重开、返回菜单不回归坏
- 经验掉落、升级三选一、Boss 预警继续正常
