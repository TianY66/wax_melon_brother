# 冬瓜兄弟：部署说明与项目总结

## 1. 部署说明

### 1.1 当前版本定位

当前版本定位为“角色差异化 + 商店化可玩版”，已经具备完整的选角、战斗、升级、波间消费和 Boss 节奏闭环。

### 1.2 推荐开发环境

- 引擎：Godot 4.x
- 系统：Windows 10 / 11
- 版本管理：Git

### 1.3 构建前检查清单

- 主菜单、角色选择、战斗、结算流程可跑通
- `data/characters.json`、`waves.json`、`upgrades.json` 已纳入构建
- 角色贴图与背景图路径正常
- 商店与升级面板无阻断性问题

### 1.4 打包要点

1. 确认主场景为 `Main`
2. 冷启动验证主菜单正常显示角色卡片
3. 至少验证一次商店流程和一次 Boss 流程

## 2. 交付清单

建议对外演示至少包含：

- 可运行游戏包
- 角色与商店版本说明
- 本套同步后的设计文档

## 3. 项目总结

### 3.1 当前成果定位

《冬瓜兄弟》当前已经从“最小闭环 MVP”进入“有角色差异和中局消费决策的可玩版”。

本版核心价值：

- 双角色开局差异明确
- 6 段波次结构清晰
- 经验升级与材料商店分工明确
- 10 分钟单局节奏更接近成熟生存构筑玩法

### 3.2 当前版本亮点

1. 冬瓜大哥与冬瓜二哥具备不同开局体验。
2. 波间商店让每波结束都有新的决策点。
3. 配置驱动程度更高，适合继续调平衡和扩内容。

### 3.3 本版刻意取舍

为了保持范围稳定，本版仍然不做：

- 局外成长
- 第 3 个角色
- 武器槽限制系统
- 商店冻结/锁卡/退款
- 多地图与复杂剧情

### 3.4 下一阶段建议

1. 扩展更多角色被动差异
2. 增加商店内稀有度表现与更丰富的经济反馈
3. 补更多敌人、精英和武器组合
4. 继续做手感、音效和视觉反馈
