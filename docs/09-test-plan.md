# 冬瓜兄弟：测试文档

## 1. 测试目标

验证《冬瓜兄弟》MVP 在功能正确性、可玩性、稳定性和性能上的基本达标情况，确保版本可用于演示与后续扩展。

## 2. 测试范围

### 2.1 功能范围
- 主菜单与开始流程
- 玩家移动、受伤、死亡
- 自动攻击与伤害结算
- 敌人行为与波次推进
- 掉落、经验、升级三选一
- 精英、Boss、胜负结算
- 暂停、设置、重开

### 2.2 非功能范围
- 性能
- 稳定性
- 基础兼容性
- UI 可用性

## 3. 测试策略

### 3.1 测试类型
- 单元测试：数值计算、升级选项过滤、波次读取
- 集成测试：战斗闭环、结算流程、设置保存
- 系统测试：完整游玩一局
- 回归测试：每次调配置后的关键功能复测
- 性能测试：中后期高密度怪潮场景

### 3.2 测试方法
- 手工测试为主
- 对纯逻辑模块补充自动化测试
- 对关键体验点做冒烟测试

## 4. 测试环境

### 4.1 目标环境
- Windows 10 / Windows 11
- 1920x1080 分辨率
- 键盘 + 鼠标

### 4.2 建议硬件
- CPU：中低端四核及以上
- 内存：8 GB 及以上
- 显卡：核显可运行，独显更佳

## 5. 进入与退出准则

### 5.1 进入准则
- 主流程功能已开发完成
- 可从菜单进入一局战斗
- 能完成一次胜利或失败结算

### 5.2 退出准则
- P0 功能无阻断性 Bug
- 核心测试用例通过率 >= 95%
- 性能测试在目标机器上可接受

## 7. 性能测试指标

### 7.1 指标
- 1080p 下目标 60 FPS
- 同屏 120 敌人 + 50 投射物时无持续严重掉帧
- 单局 10 分钟内内存占用无持续异常攀升

### 7.2 重点观察点
- 8 分钟后的高密度怪潮
- 多武器同时攻击
- 磁吸核心激活时的大量经验球吸附
- Boss 技能与护卫同场

## 8. 缺陷分级

| 级别 | 说明 |
|---|---|
| P0 | 阻断主流程，导致无法开始、游玩或结算 |
| P1 | 严重影响体验，但仍可继续游玩 |
| P2 | 一般功能缺陷或表现问题 |
| P3 | 轻微 UI、文案或特效问题 |

## 9. 回归测试建议

每次改动以下内容后需执行最小回归：

- 改武器数值后：TC-06、TC-07、TC-09、TC-10
- 改波次配置后：TC-12、TC-13、TC-14、TC-20
- 改 UI 或状态管理后：TC-02、TC-16、TC-17
- 改结算流程后：TC-05、TC-15、TC-17

## 10. 验收建议

版本对外演示前，至少完成：

1. 1 次完整胜利流程测试
2. 1 次完整失败流程测试
3. 3 次连续回归测试
4. 1 次高压性能观察
