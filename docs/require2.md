# 冬瓜兄弟：需求汇总

## 1. 当前版本定位

当前版本是“角色差异化 + 波间商店”的可玩版，不再是早期单角色 MVP。

核心范围：

- 2 个角色
- 6 段波次
- 前 5 段波间商店
- 经验升级与材料消费双循环
- Boss 终局节奏

## 2. 关键需求

### 2.1 角色

- 主菜单支持选择冬瓜大哥 / 冬瓜二哥
- 开始游戏后按所选角色注入贴图、数值、初始武器
- 重开沿用当前角色
- 返回主菜单后默认选中冬瓜大哥

### 2.2 战斗

- 玩家 `WASD` 移动
- 武器自动攻击
- 敌人刷新、追击、远程、爆炸、Boss 行为正常
- 经验掉落继续使用地面掉落物

### 2.3 升级

- 经验满后弹出三选一
- 战斗暂停
- 候选项复用统一升级池合法性规则
- 连续升多级时连续弹出，不丢级

### 2.4 波次与商店

- 6 段战斗时间轴：
  - `0-90`
  - `90-180`
  - `180-270`
  - `270-360`
  - `360-450`
  - `450-600`
- 前 5 段结束进入商店
- 若波末与升级同帧触发，先升级后商店

### 2.5 材料经济

- 敌人按类型直接入账材料
- 材料不生成地面掉落物
- 材料只在本局商店内消费

### 2.6 商店规则

- 每次商店生成 3 个商品
- 商品候选复用升级池
- 每个商店可购买多个商品
- 已购商品显示“已售出”
- 每店仅 1 次刷新
- 刷新价格固定 `8`

## 3. HUD 需求

HUD 需要显示：

- 血条
- 经验条
- 等级
- 时间
- 击杀数
- 材料数
- 波次 `Wave X/6`

## 4. 价格规则

| 类别 | 价格 |
|---|---:|
| `unlock_weapon` tier1 | 36 |
| `unlock_weapon` tier2 | 52 |
| `weapon_upgrade` tier1 | 32 |
| `weapon_upgrade` tier2 | 48 |
| `global` tier1 | 26-30 |
| `global` tier2 | 44 |
| reroll | 20 |

## 5. 验收口径

1. 双角色可选、贴图正确、初始武器正确。
2. `90/180/270/360/450s` 准时进入商店。
3. 商店中时间停止，离开后恢复。
4. 材料收支正确，买不起时禁用商品。
5. 刷新每店仅 1 次，价格固定 20。
6. Boss 预警、Boss 登场、胜负结算不回归坏。
