# 冬瓜兄弟：故事列表

## 1. 说明

以下故事列表覆盖当前可玩版本到后续演示版的主要开发内容，优先级采用 `P0 / P1 / P2`。

## 2. Epic 列表

- E1：进入流程与角色选择
- E2：战斗与成长
- E3：波次、商店与经济
- E4：Boss、反馈与结算
- E5：配置化与可维护性
